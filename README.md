# 大六壬 · 月將查詢（中國風 v2）

輸入陽曆時間，自動推算四柱（年／月／日／時）與月將，並標示該次時間所屬中氣、過中氣換將依據。

## 線上使用

https://hungpinoffice-afk.github.io/liu-ren-yuejiang/

用手機開即可，可「加入主畫面」當独立 App 用。

## 計算規則

- 年柱：立春換年
- 月柱：以「節」換月
- 月將：太陽過「中氣」即換將（雨水→登明亥、春分→河魁戌、谷雨→從魁酉……）
- 日柱：60 甲子連續推算
- 節氣時刻：依太陽視黃經推算（Meeus 演算法），誤差約數分鐘

## 使用方式

1. 輸入西元年（輸入框）＋月／日／時／分（下拉選單）
2. 點「查詢」
3. 可勾選「23 時後即算次日子時（晚子時換日）」

## 本目錄檔案

- `index.html`：單一檔案，無外部依賴，可離線開啟
- 複製到手機：把此檔傳入手機，用瀏覽器開啟即可
